# montoneras-independencia-peru

Este repositorio reúne resúmenes, notas y reflexiones personales sobre la participación de guerrillas y montoneras durante la independencia del Perú (1813–1824), elaborados a partir de fuentes históricas de la Colección Documental de la Independencia del Perú.

Los contenidos responden a un interés personal por comprender los procesos históricos desde sus condiciones económicas, sociales y políticas, tomando el materialismo histórico como una perspectiva de análisis.

Para su elaboración se utiliza NotebookLM como herramienta de apoyo en la revisión y síntesis documental, complementando las fuentes históricas con bibliografía especializada e información estadística y económica cuando se encuentra disponible.

Este espacio tiene un carácter exploratorio y de aprendizaje, por lo que las interpretaciones presentadas no constituyen conclusiones de una investigación académica formal, sino aproximaciones personales sujetas a revisión y discusión.
